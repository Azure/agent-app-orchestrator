# Contributing

Create your working branch from `develop` and open contribution pull requests
against `develop`, not `main`. Only release branches named exactly
`release/X.Y.Z` in this repository may open pull requests against `main`.

Describe the change briefly, include relevant test results, and update
documentation when needed. Pull requests run the quality gate automatically;
it must pass before merge. These checks support manual review, not replace it.

Most contributions require a Contributor License Agreement (CLA). The CLA bot
will explain any required steps when you open a pull request. See
[Microsoft's CLA](https://cla.opensource.microsoft.com/).

This project follows the [Microsoft Open Source Code of Conduct](https://opensource.microsoft.com/codeofconduct/).
See the [Code of Conduct FAQ](https://opensource.microsoft.com/codeofconduct/faq/)
or contact [opencode@microsoft.com](mailto:opencode@microsoft.com) with questions.
